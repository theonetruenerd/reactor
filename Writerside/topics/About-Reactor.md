# About Reactor

Reactor is a Java-based IDE specifically designed for lab automation and liquid handling applications. It provides a 
comprehensive development environment tailored for scientists and engineers working with laboratory equipment and 
automation workflows.

## What is Reactor?

Reactor combines the power of modern development tools with specialized features for lab automation:

- **Lab Equipment Integration**: Built-in support for connecting to and controlling liquid handling robots and laboratory 
instruments
- **Version Control**: Integrated Git support for managing your automation scripts and configurations
- **Rich Text Editing**: Advanced code editing with syntax highlighting and IntelliSense

## Key Features

### Modern JavaFX Interface
Built on JavaFX 24 with a responsive, modern user interface that adapts to your workflow needs.

### Liquid Handling Support
Specialized tools and libraries for programming liquid handling robots, pipettes, and dispensing systems.

### Advanced Code Editing
Powered by RichTextFX for advanced text editing capabilities including:
- Syntax highlighting
- Code completion
- Multi-language support via ANTLR grammar parsing

### Version Control Integration
Built-in Git support through Eclipse JGit for managing your automation projects and collaborating with team members.

## System Requirements

- **Java**: JDK 24 or higher
- **Operating System**: Windows, macOS, or Linux
- **Memory**: Minimum 4GB RAM recommended
- **Storage**: 500MB available disk space
